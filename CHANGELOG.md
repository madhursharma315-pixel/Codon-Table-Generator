# Changelog

## Version 1.0.0

* Created a Python codon table generator.
* Added the standard genetic code with 64 codons.
* Added DNA and RNA sequence input handling.
* Added codon grouping and amino acid translation.
* Added start and stop codon identification.
* Added handling for incomplete codons.
* Documented comparison with the NCBI Standard Genetic Code.
* Added unit tests for selected codon assignments.
* Documented project limitations and possible future improvements.
