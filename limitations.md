# Project Limitations

1. The program uses the standard genetic code.
2. It does not support every organism-specific genetic code.
3. Incomplete codons at the end of a sequence cannot be translated.
4. The program validates nucleotide characters but does not confirm that a sequence comes from a biological sample.
5. The program identifies ATG as the conventional start codon for this project.

## Future Improvements

* Add support for alternative genetic codes.
* Provide more detailed error messages for invalid sequences.
* Add automated tests for DNA and RNA input.
* Improve the output format for long sequences.
